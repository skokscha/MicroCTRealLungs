# MicroCTRealLungs — RVE альвеолярной паренхимы человека из микро-КТ

Построение геометрии представительного объёма (RVE) лёгочной ткани человека
напрямую из изображений синхротронной микро-КТ (HiP-CT): JP2-срезы → сегментация →
STL-поверхности обеих фаз (ткань / воздух) для дальнейших конечно-элементных
и CFD-расчётов (продувка воздуха).

```
JP2-архив (999 срезов, 4.9 мкм/воксель, 1905×1905, uint16)
   │  scripts/extract_cube.py        — чтение JP2 из zip, вырезка куба 512³
   ▼
data/cube_4.9um_512.npy
   │  scripts/mesh_cube_v2.py        — Гаусс σ=0.8 → порог Отсу (25519) →
   ▼                                 закрытие 3³ → архив маски
data/cube_4.9um_512_mask.npz         (доля ткани 16.9 %, пористость ≈ 0.83)
   │  scripts/make_rve500.py         — RVE 500 мкм: сеточный поиск позиции
   │  scripts/make_tiles.py          — 10 плиток 102³ на общей решётке
   ▼                                 (склеиваются в большой объём без швов)
STL обеих фаз: *_tissue / *_air (+ *_raw / *_smooth)
   │  scripts/blender_smooth_tiles.py — Taubin-сглаживание (SMOOTH +0.5/−0.53)
   │  scripts/blender_render_only.py  — контрольный рендер (Cycles)
   ▼
вход для FEM / CFD (OpenFOAM, COMSOL, Abaqus...)
```

| 10 плиток для склейки | `data/tiles/` | единая решётка (база 1, шаг 102 вокс.), raw + smooth, ткань + воздух, маски с офсетами |
| Контроль сегментации | `data/**/overlay*.png`, `data/preview/mask_overlay_*.png` | контур маски на срезах |
| Рендеры | `data/rve500/rve500_render.png`, `data/tiles/render_*.png` | Blender/Cycles |
| Отчёт | `REPORT_human_lung_RVE.md` | полный протокол работы |
| Обоснование методики | `JUSTIFICATION_RVE_defense.md` | аргументы для защиты перед комиссией |
| Разбор кода + план CFD | `CODE_EXPLAINED_and_AIRFLOW_plan.md` | обоснование каждого шага + маршруты продувки воздухом |

Морфометрия: воксель 4.9 мкм; большой куб 2.5 мм — ткань 16.9 %; RVE500 —
ткань 0.0211 мм³ / воздух 0.1038 мм³; плитки — доля ткани 0.076–0.264
(реальная неоднородность паренхимы).

## Исходные данные и атрибуция (обязательно при использовании)

Датасет: **Human Organ Atlas**, ESRF, HiP-CT (BM05) —
`LADAF-2020-27_lung-left_VOI-06-lower-lobe-basal`,
DOI: [10.15151/ESRF-DC-572194514](https://doi.org/10.15151/ESRF-DC-572194514).
Использован «лёгкий» JP2-пакет 4.9 мкм (725 МБ), скачивается с портала HOA.

При публикации результатов на этих данных цитировать:
The Human Organ Atlas Collaboration, Walsh C. L. et al. (полный список авторов —
в метаданных датасета, поле `citation`).

Методологические референсы: Rausch et al. 2011; Concha et al. 2015; Roth et al. 2015;
Sarabia-Vallejos, Zúñiga & Hurtado, Sci Rep 9:8783 (2019), doi:10.1038/s41598-019-45343-4.

## Воспроизведение

```bash
python -m venv .venv && .venv/Scripts/pip install -r requirements.txt
# положить 4.9um_..._jp2_.zip в корень (скачать с human-organ-atlas.esrf.fr)
python scripts/extract_cube.py        # куб 512³ (~2 мин)
python scripts/mesh_cube_v2.py        # сегментация + маска
python scripts/make_rve500.py         # RVE 500 мкм, обе фазы
python scripts/make_tiles.py          # 10 плиток на общей решётке
blender --background --python scripts/blender_smooth_tiles.py -- "<abs path>/data/tiles"
```

Тяжёлые бинарники (zip 725 МБ, .npy, .stl, маски) в репозиторий не входят —
они регенерируются скриптами из исходного архива; в git лежат только код,
отчёты и лёгкие превью (оверлеи, рендеры).

## Замечания

- Поверхности STL не watertight (перегородки 1–3 вокселя на 4.9 мкм) — перед
  объёмной сеткой нужен ремонт (`pymeshfix` / MeshLab) или пересборка из
  полных 2.45-мкм данных; шаги описаны в `PROMPT_openfoam_airflow.md`.
- Воксельные маски — почти готовая гексаэдральная КЭ-сетка (1 воксель = 1 гексаэдр),
  альтернатива тетраэдризации по STL.
- Децимация кластеризацией вершин для этой геометрии запрещена (шипы-«ёжик»);
- сглаживание — только Taubin (λ/μ, без усадки объёма).
